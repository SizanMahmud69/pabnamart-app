
# পাবনা মার্ট - ডোমেইন কানেক্ট করার গাইড (Vercel) 🌐

আপনার ওয়েবসাইটটি ইতিমধ্যে Vercel-এ লাইভ আছে। এখন আপনার কেনা ডোমেইন `pabna-mart.shop` এর সাথে এটি কানেক্ট করতে নিচের ধাপগুলো অনুসরণ করুন:

### ধাপ ১: Vercel-এ ডোমেইন যোগ করা
১. আপনার ফোনের ব্রাউজার থেকে [vercel.com](https://vercel.com) এ লগইন করুন।
২. আপনার প্রজেক্টটি (`pabna-mart`) সিলেক্ট করুন।
৩. উপরে থাকা **Settings** ট্যাবে ক্লিক করুন।
৪. বাম পাশের মেনু থেকে **Domains** অপশনে যান।
৫. "Add" বাটনে ক্লিক করে আপনার ডোমেইন নাম `pabna-mart.shop` লিখুন এবং **Add** দিন।
৬. Vercel আপনাকে ডোমেইন ভেরিফাই করার জন্য কিছু **DNS Records** (A record এবং CNAME) দেখাবে। এগুলো নোট করে নিন বা কপি করুন। সাধারণত এগুলো এমন হয়:
   - **A Record:** Name: `@`, Value: `76.76.21.21`
   - **CNAME Record:** Name: `www`, Value: `cname.vercel-dns.com`

### ধাপ ২: DNS রেকর্ড আপডেট করা (আপনার ডোমেইন প্যানেলে)
১. যে ওয়েবসাইট থেকে ডোমেইন কিনেছেন (যেমন: `shodns.in`), তাদের কাস্টমার প্যানেলে লগইন করুন।
২. **My Domains** এ গিয়ে আপনার ডোমেইনটি সিলেক্ট করুন।
৩. সেখানে **DNS Management** বা **Manage DNS** অপশনটি খুঁজে বের করুন।
৪. Vercel থেকে পাওয়া রেকর্ডগুলো এখানে যোগ করুন:
   - আগে থেকে যদি কোনো **A Record** থাকে, সেটি পরিবর্তন করে Vercel-এর দেওয়া IP (`76.76.21.21`) বসিয়ে দিন।
   - একটি নতুন **CNAME Record** তৈরি করুন যেখানে Host হবে `www` এবং Value হবে `cname.vercel-dns.com`।
৫. সব সেভ (Save) করুন।

### ধাপ ৩: অপেক্ষা করুন
DNS পরিবর্তনগুলো কাজ করতে সাধারণত ৩০ মিনিট থেকে ২ ঘণ্টা সময় নেয় (কখনো ২৪ ঘণ্টা লাগতে পারে)। ভেরিফিকেশন হয়ে গেলে Vercel-এ ডোমেইনটির পাশে সবুজ রঙের "Valid" লেখা দেখতে পাবেন। এরপর থেকে সরাসরি `pabna-mart.shop` লিখলেই আপনার ওয়েবসাইট ওপেন হবে।

---
**প্রয়োজনীয় তথ্য:**
- আপনার কেনা cPanel হোস্টিং এর প্রয়োজন এখন নেই, শুধু ডোমেইনটি ব্যবহার করলেই হবে।
- হোস্টিং এর Nameservers পরিবর্তন করার প্রয়োজন হলে Vercel-এর নিজস্ব Nameservers ব্যবহার করতে পারেন (এটি আরও ভালো কাজ করে):
  - `ns1.vercel-dns.com`
  - `ns2.vercel-dns.com`
  (যদি এটি ব্যবহার করেন, তবে Vercel অটোমেটিক সব DNS সেটআপ করে নেবে)।
